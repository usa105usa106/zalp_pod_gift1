# QR-вход для Gift Hunter v0042 (дополнение, hotfix)

Исходная логика бота не изменена. Новая команда:

```bash
docker exec -it <ID_ВТОРОГО_КОНТЕЙНЕРА> python /app/main.py auth_qr
```

Открой **второй** Telegram-аккаунт -> Настройки -> Устройства -> Подключить устройство.
Отсканируй QR с другого устройства/экрана. На телефоне, где запущен терминал,
сканировать QR из того же самого терминала камерой неудобно,
поэтому лучше открыть терминал на компьютере.

В терминале QR отображается Unicode-символами; если неудобно сканировать,
картинка временно сохраняется в DATA_DIR как auth_qr_TEMPORARY.png и
удаляется после завершения команды. Она конфиденциальна!

Если для аккаунта включён 2FA, после сканирования введи свой
2FA-пароль в терминале. Не вводи его в чат бота.

**Не запускай эту команду в ПЕРВОМ контейнере.** Настройки с
API_ID, API_HASH и номером второго аккаунта должны быть уже сохранены.
Новое развёртывание должно иметь свои Docker volumes.
