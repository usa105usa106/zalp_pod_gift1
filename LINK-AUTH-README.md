# Gift Hunter v0042 — авторизация Telegram по ссылке (hotfix)

Добавлена **`auth_link`**, без изменений алгоритмов поиска/покупки подарков.
Команда **`auth_qr`** сохранена как запасной вариант.

## Установка только во второй бот

1. В репозитории `zalp_pod_gift1` замените файлы проекта содержимым папки `gift_hunter_v0042/` из этого архива.
2. В Coolify сделайте Deploy только **второго** приложения. Не изменяйте проект работающего первого бота.
3. В Termius подключитесь к VPS и определите ID **нового** контейнера через `docker ps`.
4. Запустите, заменив идентификатор на актуальный:

```bash
docker exec -it ID_ВТОРОГО_КОНТЕЙНЕРА python /app/main.py auth_link
```

5. В терминале появится временная ссылка формата `tg://login?token=...`. Попробуйте открыть её на **том же телефоне**, где авторизован **второй** аккаунт Telegram. Если Telegram предложит подтвердить вход — подтвердите его. При запросе 2FA введите облачный пароль **в Termius**.
6. После успешного входа терминал покажет Telegram ID и сохранит сессию именно в рабочем каталоге этой установки. Перезапустите **только второй сервис** через Coolify, затем проверьте авторизацию через бота.

## Предупреждения

- **Вход по такой ссылке на одном телефоне не гарантирован**: Telegram может не показать подтверждение. Это тот же токен, что используется в QR-входе, только текстом. Если не сработает, запустите `auth_qr` и покажите QR на ноутбуке через SSH/Termius (сам Telegram и VPN на ноутбуке для этого не нужны).
- Ссылка действительна примерно 30 секунд; новая ссылка автоматически появляется после истечения старой.
- **Не публикуйте ссылку, QR-код или `.session`**. Не присылайте фото терминала с активной ссылкой в чат.
- Команда работает с **настройками и сессией только контейнера, где она запущена**. В уже авторизованном контейнере она откажется менять сессию.
- Авторизация создаётся в отдельной временной SQLite-сессии, затем атомарно подменяет только локальный рабочий файл. При наличии старого файла предварительно делается резервная копия.
- Важно: файлы сессии должны храниться в постоянном volume/bind mount. Иначе при пересоздании Docker-контейнера авторизация может пропасть. Проверьте это в Coolify, прежде чем делать ещё один Deploy.

`auth_link` — экспериментальный метод подтверждения с одного телефона, не протестированный на вашем конкретном Android/Telegram.
