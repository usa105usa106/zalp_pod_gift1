# Changelog

## v0020-fast — Hunter 2 — FAST

- Версия приложения обновлена до `v0020-fast` во всех пользовательских и служебных местах.
- Внутренний лимит одного улучшения по умолчанию установлен на `3000 ⭐` через `DEFAULT_MAX_UPGRADE_STARS`.
- Тихая FAST-зона по умолчанию начинается за `5` номеров до цели через `DEFAULT_FAST_QUIET_DISTANCE`.
- Обновлены `.env.example`, Docker Compose, README, healthcheck и тесты новых значений по умолчанию.

## v0020-fast — Hunter 2 — FAST

- Создан отдельный продукт и отдельное имя версии, чтобы не обновлять работающий v0018.
- Удалена дополнительная проверка целевого slug после точного появления `цель − 1`.
- Платёжный MTProto request создаётся одновременно с формой и хранится готовым в памяти.
- FAST-путь запускает финансовый request до логов, UI и дисковых записей.
- Удалён pre-submit `payment_hold`; неизвестный результат сохраняется на сверку только после первого запроса.
- Запрещены обновление формы и автоматический повтор внутри FAST-submit.
- Добавлен одноразовый RAM-флаг, не позволяющий повторить залп в том же процессе.
- Добавлен тумблер залпа `1–5`; несколько запросов запускаются конкурентно.
- Изменение размера залпа выключает LIVE и требует повторного подтверждения возможного расхода.
- Добавлена тихая зона: отмена монитора карточки, пропуск агрегатного счётчика и временное отключение GC.
- Добавлен необязательный `FAST_CPU_AFFINITY`.
- Добавлен явный `MT_SESSION` для безопасной изоляции второго аккаунта.
- Docker Compose использует отдельный сервис и отдельный volume `hunter_2_fast_data`.
- Добавлены тесты однократного FAST-залпа, конкурентного запуска 3 запросов, post-submit hold и тумблера 1–5.
